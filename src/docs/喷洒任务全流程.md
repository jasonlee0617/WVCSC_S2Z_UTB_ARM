阶段 1：MOVING_TO_OBSERVE — 动态观察位姿
做什么：根据 tree_hint（果树在 alicia_base_link 下的坐标），计算一个让 C10 相机光轴对准树冠的安全观察姿态，并通过 MoveIt 规划执行。

对应代码：spray_task.py:508-521 → 调用 observation.py:_move_to_observation() → observation.py:925-955

详细步骤：


1. 从 Action Goal 中读取 tree_hint (PoseStamped)
   source: spray_task.py:511  _move_to_observation(request.tree_hint)

2. TF 变换：tree_hint 从 map 坐标系变换到 alicia_base_link 坐标系
   source: observation.py:931-938
   → tree_in_base = (tx, ty, tz)  # 果树在臂基座坐标系中的 3D 位置

3. 获取 tool0 → camera_color_optical_frame 的固定 TF
   source: observation.py:940-941
   → camera_mount = (translation_xyz, rotation_xyzw)  # eye-in-hand 外参

4. ObservationOptimizer.generate() 生成候选网格
   source: observation.py:966-967
   输入: tree_in_base, camera_mount, camera_intrinsics
   网格: distance × camera_height × azimuth_offset
   输出: N 个 ObservationCandidate (每个含 tool_position, tool_quat, ...)

5. 视野筛选: 保留果实区域中心可见且有效覆盖率达标的候选
   source: observation.py:968, candidate.visible 字段
   → 使用当前内参补偿主点偏移，使区域中心落在图像中心
   → 相机正对面的果实区域投影与有效图像交集必须达到 60%

6. 碰撞 IK 求解: 逐个候选计算 IK
   source: observation.py:987 arm.compute_ik(...)
   → 过滤掉碰撞或 IK 无解的候选

7. 运动学指标评估
   source: observation.py:994 observation_optimizer.evaluate_ik(...)
   评估: 雅可比条件数 (≤ max_condition_number)
         关节余量 (≥ min_joint_margin_rad)

8. 排序: 按条件数×关节余量加权排序
   source: observation.py:1001 observation_optimizer.rank()

9. 尝试执行: 从排名最高的候选开始
   source: observation.py:1010-1041 _move_to_next_observation()
   → arm.plan_pose() → arm.execute_trajectory()
   → 执行后重新验证实际关节角的安全性 (post-motion IK check)

10. 成功 → 记录 observation_pose, observation_distance
    fail → 尝试下一个候选 → 全部失败 → OBSERVE_FAILED
关键参数（arm_task.yaml）：


observation_distance_min_m: 1.10  # 相机到树的水平距离
observation_distance_max_m: 1.50
camera_height_min_m: 0.20         # 相对 alicia_base_link 的相机光心 Z 高度
camera_height_max_m: 0.40
camera_height_step_m: 0.10
observation_max_condition_number: 16.0
observation_min_joint_margin_rad: 0.18
observation_max_plans: 8           # 最多保留 8 个候选
observation_min_visible_fraction: 0.60

`camera_height_*` 直接描述相机光心在 `alicia_base_link` 下的 Z 高度。
`0.20 m` 是当前确认的最小车顶净空；候选仍必须通过碰撞 IK、雅可比条件数和
关节余量筛选，不能通过降低这些阈值进入视觉伺服。

阶段 2：SCANNING_TREE — YOLO 果树确认
做什么：用 YOLOv8n 检测 tree 类别，确认果树在相机视野中。若未检测到，按预制偏航角偏移扫描。

对应代码：spray_task.py:523-531 → 调用 observation.py:_scan_for_tree() → observation.py:571-596

详细步骤：


1. 发布推理模式切换
   source: spray_task.py  _set_inference_mode('tree')
   → YOLO 只运行 tree 检测（停止 fruit 分割，节省 GPU）

2. 生成扫描姿态列表
   source: observation.py:ObservationOptimizer.order_for_tree_scan()
   scan_poses = [中心正对树姿态, 同距离同高度的 -12° / +12° 扇形姿态, 其余侧向恢复姿态]
   参数: observation_azimuth_offsets_deg: [0.0, -12.0, 12.0]

3. 逐个扫描姿态尝试
   for each pose in scan_poses:
       a. arm.move_pose(pose) → 移动到该姿态 (observation.py:576)
       b. _wait_for_tree(cancel_requested) → 等待 tree 检测 (observation.py:608-617)
          → 订阅 /vision/tree_detections (Detection2DArray)
          → 要求连续 confirmation_frames=3 帧检测到 tree (class_id='tree')
          → 每姿态最多等 scan_pose_detection_timeout_sec=5.0s
       c. 找到 → 记录为 observation_pose，返回 True
       d. 中心姿态未找到 → 依次尝试 -12°、+12°；同组不可用时才进入其余安全侧向恢复姿态

4. 全部姿态失败 → VISION_FAILED
YOLO 订阅回调：spray_task.py: _on_tree_detections()


# 订阅 /vision/tree_detections，过滤 class_id='tree' 且 conf ≥ tree_confidence
# 每次收到消息: self._tree_frames += 1 (目标流层负责连续性检查)
阶段 3：DETECTING_FRUITS — 果实实例分割
做什么：YOLOv8n-seg 运行完整推理（tree + diseased_fruit），等待稳定候选。

对应代码：spray_task.py:548-566 → 调用 target_flow.py:_wait_for_fruits() → target_flow.py:293-387

详细步骤：


1. 发布推理模式切换
   source: spray_task.py:550  _set_inference_mode('fruits')
   → YOLO 运行完整模型 (tree detect + fruit instance segmentation)

2. 等待稳定候选
   source: target_flow.py:293 _wait_for_fruits(cancel_requested)
   timeout = detection_timeout_sec (2.0s)
   
   循环内部:
   a. 检查共享视觉快照 (vision_mutex 保护)
   b. 要求 _fruit_frames ≥ confirmation_frames (3帧) 
      且有至少一个候选的目标ID在连续的这几帧均出现
   c. 超时 → 返回 [] (空列表) 或 None (硬超时)
   
   关键：_wait_for_fruits 不再在无候选时提前返回
   (fix: target_flow.py:310-314, 只有 candidates 非空才 return)

3. 接收 YOLO 检测帧
   source: spray_task.py: _on_fruit_detections()
   订阅 /vision/fruit_detections (Detection2DArray)
   → 过滤 class_id='diseased_fruit' 且 conf ≥ fruit_confidence
   → 维护 _fruit_counts = {target_id: 出现次数}
   → 维护 _fruit_latest = {target_id: 最新 FruitTarget}

4. 返回 candidates: List[FruitTarget]
   每个 FruitTarget 含: target_id, confidence, center_u, center_v, width, height
阶段 4：QUEUING — 去重排序
做什么：对检测结果去重（与已处理和已耗尽目标比较），按距离图像中心由近到远排序。

对应代码：spray_task.py:569-590 → 调用 target_flow.py:_queue() → target_flow.py:389-410

详细步骤：


1. 过滤已处理/已耗尽的果实
   source: target_flow.py:389 _queue(candidates, processed + exhausted)
   → IoU ≥ processed_iou_threshold (0.30) → 视为同一目标，排除
   → 中心距离 ≤ processed_center_distance_px (40px) → 视为同一目标，排除

2. 帧内去重
   source: target_flow.py:398-403
   → IoU ≥ 0.35 或中心距离 ≤ 10px → 同一物理果实，只保留置信度最高者

3. 排序
   source: target_flow.py:405-410
   主键: 距离图像中心(640,360)的欧氏距离 (近的优先)
   次键: confidence 降序

4. 更新已知目标列表
   source: spray_task.py:574-583
   → _remember_targets(known_targets, candidates) 
   → 若 pending_attempt 存在(从恢复中来)，尝试 re-associate 原始目标
阶段 5：ALIGNING — 重心 + IBVS 对准
做什么：先由 `/vision/compute_spray_aim` 在当前固定工距计算喷嘴轴线投影像素；对队列首目标相对该像素执行重心修正（偏差 >48 px 时触发），随后以同一像素进入 IBVS 微调。

对应代码：spray_task.py:639-720 → observation.py:_recenter_target() → IBVS 通过 AlignTarget Action

详细步骤：


1. 选择目标
   source: spray_task.py:639-660
   → 若 pending_attempt 非空（观察恢复后），优先匹配原目标
   → 否则选 queue[0]（距离图像中心最近的目标）
   → 尝试关联到已有的 TargetAttempt 记录

2. 发布选中目标
   source: spray_task.py:661-662
   → _select_target(target.target_id)
   → YOLO 节点收到后开始发布只包含此目标的对准信息
   → _set_inference_mode('target')

3. 重心修正 (Recenter)
   source: observation.py:598 _recenter_target(target, attempt, cancel_requested)
   触发条件: 像素误差 > target_recenter_trigger_px（仿真 16px）
   
   a. 计算目标在图像中的像素偏差
   b. 调用 recenter_camera_pose + tool_pose_from_camera_pose
      生成使目标接近已标定喷嘴投影点的修正姿态；不使用图像中心兜底
   c. 最大旋转 ≤ target_recenter_max_angle_deg (20°/次)
   d. 最大迭代 ≤ target_recenter_max_iterations (2次)
   e. arm.plan_pose → arm.execute_trajectory → 后安全检查
   f. 细化目标: 逐级尝试 residual_candidates [12, 16, 24, 8, ...] px

4. IBVS 视觉伺服 (AlignTarget Action)
   source: spray_task.py:699 self._align_target(...)
   → 调用 visual_servo_node (AlignTarget action server)
   → PID 控制器 (visual_servo.yaml: pid_kp_xy=4.0)
   → 30Hz 控制频率，angular_xy 模式
   → 目标: 圆形像素误差 ≤ fine_tolerance_px (仿真为 4px)，连续 stable_duration_sec (0.5s)
   
   伺服内部循环:
   a. 订阅 /vision/target (Target2D 消息)
   b. 计算误差 = target - desired，其中 desired 与重心阶段共用同一喷嘴轴线投影点
   c. PID 输出 TwistStamped → /servo_node/delta_twist_cmds
   d. MoveIt 重心优先将目标带到约 3px 残差；若仍超过 8px，最多追加一次通过碰撞 IK、条件数和关节余量检查的小角度细化。仿真 YOLO 的最终稳定半径为 4px（1.30m 工距下约 4.8mm，严于 ±8px 验收线）；首个目标调用 `start_servo`；每个 Action 结束发布受限零 Twist 制动；后续目标复用已启动的 Servo 循环，避免 Gazebo 组件容器的 pause/unpause 服务阻塞
   e. 每个控制周期检查: 是否对准 / 是否超时 / 是否伺服状态异常

5. 对准失败处理
   source: spray_task.py:721-782
   ├─ TIMEOUT / TARGET_STALE / SERVO_SINGULARITY (可恢复)
   │   → _recover_to_next_observation() → 换观察距离 → 重新 DETECT
   │   → max_alignment_attempts=2 次内重试
   ├─ SERVO_SAFETY_STOP → motion_control stop → INTERNAL_ERROR → 锁定
   └─ 其它 → VISION_FAILED → HOME
关键参数（arm_task.yaml）：

target_recenter_workspace_px: 16.0    # 超过此残差禁止交给 Servo
target_recenter_max_angle_deg: 20.0   # 单次最大旋转
target_recenter_max_iterations: 8     # 最大分段迭代
vision_timeout_sec: 8.0               # IBVS 对准超时
max_alignment_attempts: 2             # 最大对准重试
关键参数（visual_servo.yaml）：

fine_tolerance_px: 1.5                # 最终对准精度
stable_duration_sec: 0.50             # 稳定时间

阶段 6：SPRAYING — 喷洒执行
做什么：对准成功后，验证工作距离，发送 Spray Action。

对应代码：spray_task.py:785-810

详细步骤：


1. 停止 YOLO 推理
   source: spray_task.py:787  _set_inference_mode('idle')

2. 喷洒工作距离校验
   source: spray_task.py:788-795 (spray_task 内部)
   → |observation_distance - spray_working_distance_m| ≤ tolerance
   → 不通过 → SPRAY_FAILED

3. 发送 Spray Action
   source: spray_task.py:802 _spray_target(...)
   → /spray/execute Action (Spray.action)
   → goal: {mission_id, tree_id, duration=spray_duration, mode='continuous'}
   → 等待 duration 秒
   
4. 成功 → processed.append(target), sprayed += 1
   失败 → SPRAY_FAILED → HOME
阶段 7：RETURNING_TO_OBSERVE / HOME — 复检 + 归位
做什么：喷洒后回到观察姿态重新检测，若还有未处理果实则循环继续；否则归 HOME。

对应代码：spray_task.py:812-850

详细步骤：


1. 返回观察姿态
   source: observation.py:1150 _return_to_observation()
   → arm.move_to_pose(current_observation_pose)
   → 若失败 → HOME_FAILED

2. 重置果实跟踪
   source: spray_task.py:825  _reset_fruit_tracking()
   → _fruit_frames=0, _fruit_counts={}, _fruit_latest={}

3. 回到 while 循环顶部 (DETECTING_FRUITS)
   → 重新检测 → QUEUING → ...
   → 若队列非空: 继续下一个目标 (ALIGNING)
   → 若队列为空: 
      a. 检查是否有 pending_targets (已知但未处理的果实)
      b. 尝试安全观察视角恢复 (_recover_for_completion_scan)
      c. 超过 completion_scan_empty_limit → break

4. 返回 HOME
   source: spray_task.py:943 _return_home(cancel_requested)
   → arm.move_joints([0, 0, 0, 0, 0, 0])
   → 成功 → COMPLETED / PARTIAL_SUCCESS / INSPECTED_NO_DISEASE
   → 失败 → HOME_FAILED (触发 motion lock)
