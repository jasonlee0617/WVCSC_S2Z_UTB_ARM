# WVCSC 小车—机械臂实机完整任务操作指南

本文给出从建图、保存地图、手眼标定、单臂测试、纯导航试跑到五点完整任务的实机流程。
所有工作区脚本都从工作区根目录执行，命令行不负责手动记录任务点，Qt 负责路线记录和提交。

```bash
cd ~/WVCSC_S2Z_UTB_ARM
```

## 0. 操作前约束

1. 建图、手眼标定、单臂测试和完整任务不能同时运行。
2. 机械臂默认串口为 `/dev/my_robot`，C10 默认视频设备为 `/dev/video2`，Yesense 默认串口为 `/dev/yesense_IMU`。
3. 继电器通道 1 为广域喷洒，通道 2 为机械臂喷嘴。
4. 实机观察模式、速度和加速度来自 `arm_task_real.yaml`，当前默认是 `ik`、`0.20`、`0.20`。
5. 串口或 USB 插口变化时，先阅读《实机硬件通讯口与设备检查指南》，不要直接猜测 `ttyACM0` 编号。

## 1. 硬件通讯口快速检查

```bash
cd ~/WVCSC_S2Z_UTB_ARM
source /opt/ros/humble/setup.bash
source install/setup.bash
lsusb
dmesg --ctime | tail -n 80
ls -l /dev/video* /dev/ttyACM* /dev/ttyUSB* /dev/serial/by-id /dev/serial/by-path 2>/dev/null || true
```

机械臂和相机：

```bash
ls -l /dev/my_robot
readlink -f /dev/my_robot
udevadm info --query=all --name=/dev/my_robot | rg 'ID_VENDOR|ID_MODEL|ID_SERIAL|ID_PATH|DEVNAME'
fuser -v /dev/my_robot || true
v4l2-ctl --list-devices
v4l2-ctl --device=/dev/video2 --all
fuser -v /dev/video2 || true
```

继电器、IMU 和 CAN：

```bash
cd ~/WVCSC_S2Z_UTB_ARM
RELAY_CONFIG="$(ros2 pkg prefix controller_pkg)/share/controller_pkg/config/fault.ini"
sed -n '/^\[serial\]/,/^\[/p' "$RELAY_CONFIG"
RELAY_DEVICE=$(awk -F= '/^[[:space:]]*PortName[[:space:]]*=/{gsub(/[[:space:]]/, "", $2); print $2; exit}' "$RELAY_CONFIG")
ls -l "$RELAY_DEVICE" /dev/yesense_IMU
fuser -v "$RELAY_DEVICE" /dev/yesense_IMU || true
ros2 node list | rg 'can_bridge|yesense|wtb_car|lslidar' || true
```

发现设备异常时先修复别名、权限或占用问题，不启动完整任务。

## 2. 小车建图和地图保存

启动当前 canonical Cartographer 链：

```bash
cd ~/WVCSC_S2Z_UTB_ARM
./run_cartograph.sh
```

等价原始命令：

```bash
cd ~/WVCSC_S2Z_UTB_ARM
ros2 launch wvcsc_bringup real_cartographer.launch.py
```

该入口统一启动 CAN、底盘、LiDAR、点云转换、Yesense、EKF、Cartographer 和 RViz；建图时不启动 C10、YOLO、MoveIt 或 MissionManager。

我驾驶车辆覆盖任务区域，确认 RViz Fixed Frame 为 `map`，确认点云和 `/ekf_odom` 连续，停止车辆后保存地图：

```bash
cd ~/WVCSC_S2Z_UTB_ARM
./save_2dmap.sh
```

指定地图输出前缀：

```bash
cd ~/WVCSC_S2Z_UTB_ARM
./save_2dmap.sh "$(pwd)/src/wvcsc_bringup/maps/map_manual/orchard"
```

验收目录至少包含 `orchard.yaml` 和 `orchard.pgm` 或 `orchard.png`。新地图放入 `wvcsc_bringup/maps/`，不覆盖已验收地图。

## 3. 建图后 C10 手眼标定

标定前关闭 Cartographer、底盘控制、完整任务和单臂控制，固定 ArUco 标定板并确认相机可见。
结果应描述 `tool0 -> camera_color_optical_frame`。

实机 Qt 标定：

```bash
cd ~/WVCSC_S2Z_UTB_ARM
unset PYTHONPATH
export PYTHONNOUSERSITE=1
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch wvcsc_calibration auto_handeye.launch.py video_device:=/dev/video2 serial_port:=/dev/my_robot
```

脚本入口：

```bash
cd ~/WVCSC_S2Z_UTB_ARM
./run_calibration.sh video_device:=/dev/video2 serial_port:=/dev/my_robot
```

成功时检查 native `.calib` 和同时间戳 `.samples`。实机 `marker_rms` 仅代表样本重复性，不能单独代表绝对外参误差。

## 4. 单机械臂 Qt 喷洒测试

车辆必须停止，不能同时启动完整任务或独立机械臂驱动：

```bash
cd ~/WVCSC_S2Z_UTB_ARM
./run_real_arm_spray_server.sh
```

原始 launch 等价命令：

```bash
cd ~/WVCSC_S2Z_UTB_ARM
ros2 launch wvcsc_bringup real_arm_spray_test.launch.py \
  yolo_python_executable:="$HOME/venvs/wvcsc_yolo_ros/bin/python"
```

脚本只启动后端和 Qt，不自动发送 `/arm/execute_spray` Goal。Qt 中选择 `ik` 或 `joint_presets`、
病株侧位、喷洒时长和单臂工作距离。当前实机配置默认是 `ik`、速度 `0.20`、加速度 `0.20`：

```bash
cd ~/WVCSC_S2Z_UTB_ARM
./run_real_arm_spray_server.sh \
  observation_mode:=joint_presets \
  arm_velocity_scaling:=0.15 \
  arm_acceleration_scaling:=0.15
```

点击“启动”后，SprayTask 才执行观察位、整幅图像病态检测、目标选择、瞄准、视觉伺服、
通道 2 喷洒、复检和 HOME。点击“复位”后，确认机械臂回 HOME，状态才可再次执行。

## 5. 使用 real_system_mission 做纯导航试跑

这里的“纯导航”使用完整 Qt 入口，只创建不触发机械臂的路线点：

```bash
cd ~/WVCSC_S2Z_UTB_ARM
./run_real_system_mission.sh
```

等价原始命令：

```bash
cd ~/WVCSC_S2Z_UTB_ARM
ros2 launch wvcsc_bringup real_system_mission.launch.py \
  yolo_python_executable:="$HOME/venvs/wvcsc_yolo_ros/bin/python"
```

Qt 操作：

1. 在 RViz 使用 `2D Pose Estimate` 完成 AMCL 初始定位。
2. Qt 点击“确认当前起点”。
3. 选择“通行点”，使用 RViz `2D Goal` 记录多个导航点。
4. 不创建病株检查点，每个点“开启广域喷洒”保持“否”。
5. 点击“开始任务”，确认小车逐点导航。

验收时不应发送 `/arm/execute_spray`，也不应打开通道 1 或通道 2。

## 6. 使用 real_system_mission 执行完整任务

### 6.1 启动和预检

```bash
cd ~/WVCSC_S2Z_UTB_ARM
./run_real_system_mission.sh
```

预检地图、C10、`/dev/my_robot`、继电器、YOLO Python、当前视觉模型及其类别契约、手眼和喷嘴标定文件；出现 `[FAIL]` 时不启动真实硬件链路。

查看参数：

```bash
cd ~/WVCSC_S2Z_UTB_ARM
./run_real_system_mission.sh --show-args
```

常用临时覆盖：

```bash
cd ~/WVCSC_S2Z_UTB_ARM
./run_real_system_mission.sh \
  map:="$HOME/WVCSC_S2Z_UTB_ARM/src/wvcsc_bringup/maps/map_YYYYMMDD_HHMMSS/orchard.yaml" \
  serial_port:=/dev/my_robot \
  c10_device:=/dev/video2 \
  vision_config_file:="$HOME/WVCSC_S2Z_UTB_ARM/src/wvcsc_perception/wvcsc_rgb_vision/config/vision_real_detect.yaml"
```

### 6.2 Qt 记录路线

1. 我先完成 RViz `2D Pose Estimate`，再点击“确认当前起点”。
2. 我选择“通行点”，点击 RViz `2D Goal` 记录车辆导航点。
3. 我选择“病株检查点”，先记录车辆停车位，再按提示点击树中心并填写树根几何提示。
4. 我在任务表“广域喷洒”列逐段勾选“是”或“否”；任务中断后仍可重新修改。
5. 我保存并加载 JSON，确认点位顺序、类型、停车位和广域状态。
6. 我点击“开始任务”，Qt 才调用 `/mission/load_manual` 和 `/mission/start`。

路线点分类：

| Qt 类型 | 接口类型 | 到站后动作 |
|---|---|---|
| 通行点 | `POINT_TRANSIT` | 关闭广域、执行通行点停稳确认或停留，然后继续 |
| 病株检查点 | `POINT_INSPECT` | 停稳 `1.0 s` 后发送一次 `ExecuteSpray` |
| 最后一个点 | 数组最后元素 | 自然结束路线，不使用额外 FINISH 类型 |

当前通行点停稳确认由 `transit_stop_stable_duration_sec` 配置，当前为 `0.1 s`；设为 `0.0` 时只跳过通行点软件确认，不会把独立 `NavigateToPose` 变成连续穿点导航。

### 6.3 广域喷洒数据流

进入某点的导航段 `wide_spray_on_approach=true` 时，MissionManager 必须同时确认：

1. Nav2 Goal 已接受；
2. 里程计新鲜；
3. 车辆线速度达到 `0.03 m/s`；
4. `/relay/set` 通道 1 开启成功。

车辆开始运动后才打开广域喷洒。到站、持续停车、导航失败、终止、HOME 或路线结束时，
通道 1 关闭；里程计失联也会立即请求关闭。

### 6.4 机械臂喷洒数据流

当前点必须是 `POINT_INSPECT`，且 Nav2 到达、车辆停稳、任务没有终止后，MissionManager
才发送 `/arm/execute_spray`。SprayTask 负责：

```text
观察位
→ 整幅图像病态检测
→ 目标稳定确认与队列
→ ComputeSprayAim
→ AlignTarget / 允许的软件回退
→ 通道 2 定时喷洒
→ 回观察位并复检剩余目标
→ 整株喷后等待
→ HOME
```

实机默认视觉入口为 `vision_real_detect.yaml` 的 detect 模型；比较 segment 时显式传入：

```bash
cd ~/WVCSC_S2Z_UTB_ARM
./run_real_system_mission.sh \
  vision_config_file:="$HOME/WVCSC_S2Z_UTB_ARM/src/wvcsc_perception/wvcsc_rgb_vision/config/vision_real.yaml"
```

两种模型保持 `/vision/*` 话题不变；detect 的控制点是框中心，segment 的控制点是掩膜安全点。

### 6.5 终止和复位

Qt 点击“终止任务”后，系统执行取消、关闭通道 1/2、机械臂停止和 HOME。只有 HOME 完成、
状态重新回到可执行状态后，才能再次点击“开始任务”。如果第二次启动时病株点被跳过，我先
检查 `/mission/status`、`/arm/execute_spray` 服务端、继电器和机械臂锁状态，不重复发送 Goal。

## 7. 完整任务验收清单

- [ ] 地图来自本次建图并能在 RViz 正确显示。
- [ ] AMCL 初始定位有效，Qt“确认当前起点”可用。
- [ ] `/camera/color/image_raw`、`/imu`、`/ekf_odom`、`/scan` 或点云链路有效。
- [ ] `/dev/my_robot`、继电器端口和 `/dev/yesense_IMU` 未被其他程序占用。
- [ ] 手眼和喷嘴标定文件通过预检。
- [ ] 视觉模型任务类型与 `vision_config_file` 一致。
- [ ] `TRANSIT` 点不发送机械臂 Action。
- [ ] `INSPECT` 点只有到达并停稳后才发送机械臂 Action。
- [ ] 广域喷洒只由导航段标志、车辆运动和通道 1 成功共同触发。
- [ ] 喷嘴喷洒只由 SprayTask 负责，使用通道 2。
- [ ] 终止、失败和 HOME 后两路继电器均请求关闭。

## 8. 常见错误定位

| 现象 | 优先检查 |
|---|---|
| Qt 起点按钮灰色 | RViz `2D Pose Estimate`、AMCL、`/amcl_pose` 和 RViz 话题 |
| `/mission/load_manual` 不可用 | MissionManager 是否因预检失败未启动 |
| 预检提示模型错误 | `vision_config_file`、任务类型、类别 ID 和原生类别名 |
| 机械臂不动作 | 当前点是否为 `INSPECT`、车辆是否停稳、Action 服务端是否在线 |
| 广域不打开 | 段标志、车辆速度、里程计新鲜度和通道 1 服务 |
| 启动后串口占用 | `fuser -v`、重复驱动或 USB 别名指向错误 |
| 小车无导航 | `/ekf_odom`、`/scan`、CAN、地图和 Nav2 生命周期状态 |

所有问题先依据终端日志和 ROS 话题证据定位，不通过删除安全门控或绕过预检解决。
